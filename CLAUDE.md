## Project

Single-page portfolio for **Fool's Cauldron**, a professional miniature painting commission service for wargames and collectible miniatures. Medieval aesthetic.

## Architecture

Single webpack entry point: `src/js/main.js` → `bundle.js`. HTML is generated by HtmlWebpackPlugin from `src/index.pug`.

**JS modules** (`src/js/`):
- `main.js` — entry point, imports SCSS and modules
- `anchors.js` — smooth scroll on nav links + mobile menu toggle
- `gallery.js` — filtering by painting level + Masonry layout
- `lang.js` — i18n system with dynamic language switching (FR/EN)
- `instagram.js` — Instagram feed loading and rendering
- `form.js` — contact form submission handling
- `lightbox.js` — image lightbox functionality

**SCSS** (`src/scss/`): `main.scss` uses `@use` (not `@import`) to load partials. Variables are in `_variables.scss`; each partial that uses them declares `@use 'variables' as *` at the top of the file.

**Built output** (committed for GitHub Pages): `dist/index.html`, `dist/bundle.js`, `dist/assets/`.

## Stack

- **Webpack 5** — config in `webpack.config.js`, native asset modules for images/fonts
- **Pug 3** + `@webdiscus/pug-loader` — all markup in `src/index.pug`
- **Dart Sass** (`sass`) + `sass-loader` — `@use`/`@forward` syntax only
- **PostCSS** with `postcss-preset-env` and `cssnano`
- **Babel** with `@babel/preset-env` (targets in `browserslist` in `package.json`)
- **Masonry.js** (`masonry-layout`) — gallery layout, initialized in `gallery.js`

## Typography

Custom fonts and Google Fonts loaded in `<head>` of `src/index.pug`:
- `Crusades` — brand name only (via `.brand-name` class), serif medieval style
- `UnifrakturMaguntia` — reserved for future use if needed
- Body text: `system-ui` (native system fonts)

Font strategy:
- `.brand-name` spans get `$font-brand` (Crusades)
- All other headings (h1-h6) use `font-weight: normal` to override browser defaults
- Section titles and body text use `system-ui`

## Gallery

Gallery items (`.gallery__item`) have a `data-level="tournament-ready"` or `data-level="tabletop-plus"` attribute. Filtering toggles the `.is-hidden` class (`display: none`) then calls `msnry.layout()`.

Columns are defined by `.gallery__sizer` width (25% → 33% → 50% → 100% by breakpoint). When real images are added, integrate `imagesLoaded` to recalculate layout after loading.

Gallery images are dynamically scanned from `src/assets/media/{tournament-ready,tabletop-plus}/` during build by `scripts/generate-gallery.js` and injected into the Pug template via a custom loader (`loaders/pug-with-gallery.js`).

## Internationalization (i18n)

The site supports French (FR) and English (EN).

**Translation files:**
- `src/js/translations.fr.js` — French translations
- `src/js/translations.en.js` — English translations

**i18n attributes in Pug:**
- `data-i18n="key"` — set element's text content
- `data-i18n-html="key"` — set element's innerHTML (for HTML tags like `<br>`)
- `data-i18n-placeholder="key"` — set input/textarea placeholder
- `data-i18n-aria="key"` — set aria-label attribute
- `data-i18n-alt="key"` — set img alt attribute

Language is detected from browser (`navigator.language`) and stored in localStorage. Users can toggle languages via buttons in the nav.

## Contact Form

The form's `action` attribute points to `https://api.web3forms.com/submit` with an access key for handling submissions.

Form includes:
- Honeypot field (invisible, prevents spam)
- Real-time feedback for send status
- Success/error messages handled by `form.js`

## Instagram Integration

Instagram posts are fetched from a pre-built JSON file (`src/assets/data/instagram.json`) generated by GitHub Actions.

**GitHub Actions workflow** (`.github/workflows/instagram.yml`):
- Runs on schedule or manual trigger
- Fetches posts from Instagram Graph API using `INSTAGRAM_ACCESS_TOKEN` and `INSTAGRAM_USER_ID` secrets
- Generates `src/assets/data/instagram.json`
- Posts and pushes to the repo

**To set up:**
1. Add `INSTAGRAM_ACCESS_TOKEN` and `INSTAGRAM_USER_ID` as GitHub Secrets
2. Manually trigger the workflow to generate the JSON
3. The site will display real Instagram posts once configured
